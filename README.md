## 🟢 Task 1 — ChatSphere

**ChatSphere** is a web-based chat application developed using Python and Flask. It allows users to register, log in, manage profiles, and communicate through chat rooms.

### ✨ Features

- User Registration
- User Login & Logout
- Profile Management
- Chat Rooms
- Real-time Chat Functionality
- Responsive Web Interface
- QR Code Scanner
- Session Management
- Database Integration

### 🛠️ Technologies Used

- JavaScript
- SQLite
- Git & GitHub
